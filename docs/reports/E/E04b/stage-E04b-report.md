# E04b 阶段报告 · Embedding 模型对照（多语言 / 中文 / 英文 / Qwen3）

- 实验：E04b（E 计划；E04 的延伸 —— 更换 Embedding 模型）
- 状态：⚠️ **部分未通过**（`Qwen3-Embedding-0.6B` PASS；`bge-large-zh` / `bge-large-en` FAIL）
- 日期：2026-10-14
- 配置：`configs/E04b_{zh,en,qwen06}.yaml`
- 基线：**E05_dense = `BAAI/bge-m3`**（多语言，`recall@5=0.963`、`mrr@5=0.7833`）
- 数据集：`data/golden/cases.jsonl`（32 题；**查询全为中文**，语料中英混合）
- 架构说明：[`stage-E04b-architecture.md`](stage-E04b-architecture.md)

## 1. 目标
验证"针对中文/英文使用不同 Embedding 模型"是否成立，并挑出本场景的最佳 Embedding。

## 2. 结果（对照 bge-m3；逐指标：含义 / 标准 / 实测 / 结论）

**判定标准**：替代模型相对 `bge-m3`：`recall@5` 回退 ≤ 0.02、`mrr@5` 回退 ≤ 0.02、`p95 ≤ 2500 ms`。

| 指标 | 它衡量什么 | 标准 |
|---|---|---|
| `recall@5` | 覆盖式召回：充分证据落入检索 top-5 的题数 ÷ 可答题数 | 回退 ≤ 0.02 |
| `mrr@5` | 首个命中证据的平均倒数排名 | 回退 ≤ 0.02 |
| `p95_latency_ms` | 端到端第 95 百分位耗时 | ≤ 2500 ms |

| 模型 | 类型 | `recall@5` | `mrr@5` | `ndcg@5` | `p95(ms)` | 结论 |
|---|---|---|---|---|---|---|
| `BAAI/bge-m3`（基线） | 多语言 | 0.9630 | 0.7833 | 0.9331 | 300 | — |
| `bge-large-zh-v1.5` | 中文 | 0.9259（recall −0.0371） | 0.7562（mrr −0.0271） | 0.9461 | 211 | ❌ **FAIL** |
| `bge-large-en-v1.5` | 英文 | 0.8148（recall −0.1481） | 0.4438（mrr −0.3395） | 0.7297 | 233 | ❌ **FAIL**（错配对照） |
| `Qwen3-Embedding-0.6B` | 多语言 | 0.9630 ✅ | 0.8716（mrr **+0.0883**） | 0.9544 | 2126 ✅ | ✅ **PASS** |

## 3. 结论
1. **中文查询 + 中英混合语料 → 多语言模型最好**：`bge-m3` 与 `Qwen3-Embedding-0.6B` 召回并列最高。
2. **"按查询语言选单语言模型"在本场景不成立**，原因有二：① 测试查询**全是中文**；② 大量题是"**中文问、英文代码**"（跨语言），
   单语言模型无法跨语言 —— 故中文模型已略降（−0.037），英文模型**大幅下降**（mrr 0.783→0.444，即"错配"的代价）。
3. **可替代方案**：`Qwen3-Embedding-0.6B` 召回持平 `bge-m3`、**`mrr` 显著更高（+0.0883）**，代价是 `p95` 2126ms；
   可作为"若排序更重要"的候选。

## 4. 边界与后续
- **真正的"中/英分别路由"需要英文查询（或英文库）** → 属 S 侧套件扩充；扩集后再做 E04c（语言路由）。
- 仅使用该 Key 的免费 Embedding 模型，未调用其它模型；密钥不入库。
- 各模型维度：zh/en/m3/Qwen3-0.6B 均为 1024（Qwen3-4B=2560、8B=4096，本次未用）。

---

## 5. 决策（2026-10-14）

依据以上实测，**当前默认 Embedding 采用多语言模型 `BAAI/bge-m3`**（本场景最优）；
单语言 `bge-large-zh/en` 均更差，**不采用**。`Qwen/Qwen3-Embedding-0.6B` 作为"排序优先"的备选保留（`mrr` 更高、延迟更高）。
